# LLMs.txt and beyond

1. Implement `llms.txt` and place it to the root of the website, follow template defined in `llms/llms-template.txt` file
2. Add link to `/llms.txt` to the website's footer: `<a href="https://example.com/llms.txt" type="text/plain" title="PRODUCT_NAME LLMs.txt">Docs for LLMs and AI-agents</a>`
3. To `<head>` of Home page __only__ add `<link rel="alternate" type="text/plain" href="/llms.txt">`
4. Implement `llms-instructions.txt` and place it to the root of the website, follow template defined in `llms/llms-instructions-template.txt` file
5. Implement `faq.txt` concentrating all FAQ sections content into this file and place it to the root of the website, follow template defined in `llms/llms-faq-template.txt` file
6. To `<head>` of FAQ page __only__ add `<link rel="alternate" type="text/plain" href="/faq.txt">`
7. Implement `about.txt` and place it to the root of the website, follow template defined in `llms/llms-about-template.txt` file
8. To `<head>` of About (or Product) page __only__ add `<link rel="alternate" type="text/plain" href="/about.txt">`
