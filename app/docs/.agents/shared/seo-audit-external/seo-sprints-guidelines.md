# Sprints schedule guidelines

Use example below as inspiration for creating a new plan. Always start with simple and basic tasks. Continue with main "must have" tasks. Followed by pre-rendering and other ostr.io services setup (web analytics, monitoring). Finishing with advisory tasks and final checkups.

## Sprint 1 (December 3 - 16)

Setup SERPs and analytic tools; Fix fundamental issues in the website implementation,
structure, and markup

### Working sessions

- 3rd December — [call] Release list of requirements, fundamental changes required for the website to kick off SEO
- 10th December — [review] Check and review changes
- 11th December — [call] Retrospective review, reiterate tasks
- 16th December — [review] Check and review changes, refine backlog

### Sprint goals

- Setup/obtain access to SERPs, Webmasters, and Analytics tools
- Ensure Analytics and Webmasters tools correctly configured
- Report website issues with fix suggestions
- Website improvements suggestions
- Review fundamental website features with improvements suggestions (SEO focused)
- Implement basic meta and Open Graph tags (multi-language improvements)
- Basic semantic HTML markup fixes

## Sprint 2 (December 17 - 30)

### Working sessions

- 17th December — [call] Release list of requirements for the sprint
- 22nd December — [review] Check and review changes
- 23rd December — [call] Retrospective review, reiterate tasks

- Ensure content availability and accessibility: Crawler/bot-specific website changes
